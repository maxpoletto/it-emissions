\section{Model Parameters and Review Scenarios}
\label{app:parameters}

This appendix inventories the configurable defaults used by the UZH IT emissions model and the additional scenario parameters introduced for the revision. Values are grouped by the model objects in the emissions calculator. The saved paper baseline uses the same calculation defaults as a new calculator configuration; its descriptive annotation differs. Displayed values may be rounded; exact inputs are retained in the saved scenario files.

Device means drive the deterministic calculation. SD, minimum, and maximum
values below are product-reference metadata, not sampled population
distributions. The low-device scenario substitutes the listed footprint minima.
The sensitivity-range columns also list exploratory alternatives; only bounds
declared in the saved scenarios enter the figure whiskers. Missing bounds mean
that uncertainty has not been quantified. Cloud and local data-center bounds are empty by default. All inclusion switches and electricity
boundaries are listed explicitly below. The six-year pooled laptop lifetime is
also retained in the managed-device sensitivity; the eight-year managed-laptop
lifetime reported in Section~\ref{sec:model:details} is not a separate modeled
cohort.
